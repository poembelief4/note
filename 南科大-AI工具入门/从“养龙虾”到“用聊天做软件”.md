# OpenClaw

要“养”小龙虾，说明小龙虾是生物，所以它得有：

- 大脑（LLM），如DS、Kimi、GPT……
- 对话方式（channel），如网页、微信、QQ……
- 工具（tools），如读取文件、修改文件、搜索、执行代码（所以有可能删除电脑上的文件，存在风险）……

与龙虾对话，龙虾通过 LLM 得出结果，再反馈给用户。

与普通对话型大模型最不一样的地方：小龙虾可以去做事情。

我们需要告诉龙虾：龙虾的身份信息和它的作用等，用户的身份信息等。

在用户的输入传递给 LLM 的时候，传递过去的信息除了用户输入的内容，还有用户的信息、龙虾的信息、龙虾应该达成的某些性质特点（Soul）、可使用的工具等，而这些额外的东西就是**提示词**。

为了让不断迭代后有效的提示词在以后类似的情况下能够被复用，我们就需要使用**技能（skills）**。

技能可以看作是规范化、增强版、可安装复用的高配“提示词”，它是个文件，有名称、介绍和具体要求。

对于龙虾使用的工具，我们是可以进行更改的。

clawhub 上有非常多可用的技能，在使用时注意是否是安全的。

小龙虾可以设定定时任务，低频执行任务；还可以使用“心跳”的功能，高频执行任务。

每次启动时，龙虾会忘记之前的东西，而为了让它记住，它会用两种记忆，一个短期一个长期：

- 短期：龙虾的日记（Daily notes）。
- 长期：Long-term，全局配置，会一直记得。

# Vibe Coding

核心：

- 自然语言主导。
- AI 主导实现：AI 负责写代码，人负责看结果。
- 对话式迭代：不断描述 $\to$ 生成 $\to$ 调整 $\to$ 尝试。
- 关注结果而非过程。

之所以称为“氛围”，是因为在实现的时候，我们是跟着感觉走，而不是精准的控制，并通过持续对话、快速反馈从而进入沉浸式创作，达到**心流状态**。

vibe coding的使用场景一般是娱乐、想法验证、快速模型、探索性开发、个人项目，但是不太适用于正式上线、运维的软件产品。
