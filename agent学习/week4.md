# 逻辑回归

逻辑回归是一种用于计算概率的极其高效的机制。

## S 型函数

逻辑函数：输出始终介于 $0\sim 1$。

标准逻辑函数（也称 S型函数）的公式如下：$f(x)=\frac{1}{1+e^{-x}}$。

其中：

- $f(x)$ 是 sigmoid 函数的输出。
- $e$ 是欧拉数，数学常数。
- $x$ 是 S 型函数的输入。

### 使用 sigmoid 函数转换线性输出

逻辑回归模型的线性组合部分为：$z=b+w_1x_1+w_2x_2+...+w_nx_n$。

其中：

- $z$ 是线性方程的输出，也称为**对数几率**。
- $b$ 是偏差。
- $w$ 是该模型学习的权重。
- $x$ 的值是特定样本的特征值。

为了获得逻辑回归预测结果，将 $z$ 值传递给 sigmoid 函数，从而得到概率：$y'=\frac{1}{1+e^{-z}}$。

其中：

- $y'$ 是逻辑回归模型的输出。
- $e$ 是欧拉数。
- $z$ 是线性输出。

## 损失和正则化

逻辑回归模型的训练过程与线性回归模型相似，有两点主要区别：

- 逻辑回归模型使用对数损失函数作为损失函数，而非平方损失函数。
- 应用正则化，防止出现过拟合。

### 对数损失函数

在输出值的变化率恒定的线性模型中，平方损失函数效果良好，但是不适用 S 型模型。

对数损失函数根据模型赋予真实类别的预测概率计算损失，预测概率越符合真实标签则损失越小，模型信心很高但预测错误则损失很大。其计算方式如下：

$对数损失=-\frac{1}{N}\sum^N_{i=1}[y_i\log(y_i')+(1-y_i)\log(1-y_i')]$。

其中：

- $N$ 是数据集中已标记的示例数量。
- $i$ 是数据集中示例的索引。
- $y_i$ 是第 $i$ 个示例的标签，必须是 0 或 1。
- $y_i'$ 是模型针对第 $i$ 个示例的预测值（介于 $0\sim1$），由 $x_i$ 中的特征集得出。

### 逻辑回归中的正则化

正则化是一种在训练期间惩罚模型复杂性的机制。

大多数逻辑回归模型采用以下两种策略降低模型复杂性：

- $L_2$ 正则化。
- 早停法。

# 分类

分类是指预测某个示例属于一组类中的哪一类。

## 阈值和混淆矩阵

分类阈值由人工选择，概率高于阈值的示例会被分配到正类别，概率低于阈值的示例会被分配到负类别，概率正好等于阈值时，分类结果取决于具体实现方式。

### 混淆矩阵

概率得分不是现实情况，也不是标准答案，二元分类器的每个输出有四种可能的结果，可以做成如下表格（称为**混淆矩阵**）：

|                | 实际正例     | 实际负例     |
| -------------- | ------------ | ------------ |
| **预测为正例** | 真正例（TP） | 假正例（FP） |
| **预测为负例** | 假负例（FN） | 真负例（TN） |

如果实际正例的总数与实际负例的总数不接近，则表示数据集不平衡。

## 准确率、召回率、精确率和相关指标

假正例越少，精确率越高；假负例越少，召回率越高。

提高分类阈值往往会减少假正例、增加假负例，而降低阈值会产生相反的效果。所以，精确率和召回率通常呈现**反比关系**。

### 准确率

准确率是指所有正确分类（不论是正类别还是负类别）所占的比例，数学定义如下：

$Accuracy=\frac{correct~classifications}{total~classifications}=\frac{TP+TN}{TP+TN+FP+FN}。$

由于准确率纳入了混淆矩阵中的所有四种情况，因此在给定平衡的数据集时，准确率可以作为模型质量的粗略衡量指标。因此，对于执行通用（或未指定）任务的通用（或未指定）模型，准确率通常是默认的评估指标。

### 召回率或真正例率

真正例率（TPR），即所有实际正例中被正确分类为正例的比例，也称为召回率或检测概率。

从数学角度来看，召回率的定义如下：

$Recall(or~TPR)=\frac{correctly~classified~actual~positives}{all~actual~positives}=\frac{TP}{TP+FN}$。

在实际正例非常少的不平衡数据集中，召回率比准确率更有意义。

### 假正例率

假正例率（FPR）是指所有实际负例中被错误分类为正例的比例，也称为误报概率，数学定义如下：

$FPR=\frac{incorrectly~classified~actual~negatives}{all~actual~negatives}=\frac{FP}{FP+TN}$。

对于不平衡的数据集，相较于准确率，FPR 通常能提供更好的信息，但如果实际负例数量非常少，就可能不是理想的选择，因为波动性较大。

### 精确率

精确率是指模型所有正类别分类中实际为正类别的比例，数学定义如下：

$Precision=\frac{correctly~classified~actual~positives}{everything~classified~as~positive}=\frac{TP}{TP+FP}$。

在实际正例数量非常少的不平衡数据集中，精确率作为指标的意义和实用性会降低。

### 指标选择和权衡

| 指标               | 指南                                                         |
| ------------------ | ------------------------------------------------------------ |
| 准确率             | 可作为平衡数据集的模型训练进度/收敛情况的粗略指标。不要用于不平衡的数据集。 |
| 召回率（真正例率） | 当假负例的代价高于假正例时使用。                             |
| 假正例率           | 当假正例的代价高于假负例时使用。                             |
| 精确率             | 当正预测的准确性非常重要时使用。                             |

## ROC 和曲线下面积

当数据集在类别之间大致平衡时，AUC 和 ROC非常适合比较模型。

当数据集不平衡时，精确率-召回率曲线（PRC）和曲线下的面积可以更好地直观比较模型性能。其中，精确率为 y 轴，召回率为 x 轴。

### 接收器操作特征曲线（ROC）

ROC 曲线直观地显示了所有阈值下的模型性能。

绘制方法：

1. 计算每个可能的阈值（在实践中是按选定的间隔）的真正例率（TPR）和假正例率（FPR）。
2. 将 TPR 和 FPR 绘制到图表中。

### 曲线下面积（AUC）

AUC 表示，如果给定随机选择的正例和负例，模型将正例排在负例之上的概率。

### 用于选择模型和阈值的 AUC 和ROC

在数据集大致平衡时，AUC 是比较两个不同模型性能的有效衡量指标。曲线下面积较大的模型通常是更好的模型。

## 预测偏差

计算预测偏差是一种快速检查，可尽早发现模型或训练数据的问题。

预测偏差是指模型预测结果的平均值与标准答案标签的平均值之间的差值。

预测偏差过大可能是这些原因造成的：

- 数据中的偏差或噪声过大，包括训练集的抽样偏差。
- 正则化过强，即模型过于简单，丢失了一些必要的复杂性。
- 模型训练流水中出现 bug。
- 提供给模型的特征集不足以完成任务。

## 多类别分类

多类别分类可视为对二元分类的扩展，适用于两个以上的类别。

如果每个示例只能分配到一个类中，则可以将分类问题处理为二元分类问题，即一个类为某个具体类，另一个类为所有其他类，然后重复分类过程即可（流程类似于 if-else 的逻辑嵌套）。

如果一个示例可以分配给多个类，那么这种分类问题就称为**多标签分类问题**。
