# 线性回归

一种用于查找变量之间关系的统计技术。在 ML 中，用于查找特征和标签之间的关系。

## 线性回归方程

代数语术：定义为 $y’=b+w_1x_1$，其中：

- $y'$  是预测标签。
- $b$ 是模型的偏差，与直线代数方程式中的 $y$ 轴截距概念相同。在 ML 中，偏差有时称为 $w_0$，是模型的形参，在训练时计算得出。
- $w_1$ 是特征的权重，与线性代数方程中的斜率 $k$ 的概念相同。权重是模型的形参，在训练时计算得出。
- $x_1$ 是一个特征。

在训练期间，模型会计算出可生成最佳模型的权重和偏差。

## 具有多种特征的模型

更复杂的模型可能依赖于多项特征，每项特征都有一个单独的权重，表示为：

$y'=b+w_1x_1+w_2x_2+w_3x_3+\dots+w_nx_n$。

# 损失函数

损失是一种数值指标，可以描述模型的预测与实际情况的偏差程度，用于衡量模型预测与实际标签之间的距离。

训练模型的目的是尽可能降低损失，使其达到最低值。

## 损失距离

损失侧重于值之间的距离，而非方向，所以损失没有负值，在计算时需要移除符号。

有两种常见的移除符号的方法：

- 计算实际值与预测值之差的绝对值。
- 计算实际值与预测值之差的平方。

## 损失类型

主要有五种类型的损失：

| 损失类型            | 定义                                 | 公式                                      |
| ------------------- | ------------------------------------ | ----------------------------------------- |
| $L_1$ 损失          | 预测值与实际值之间的差的绝对值之和。 | $\sum|实际值-预测值|$                     |
| 平均绝对误差（MAE） | 一组 $N$ 个示例的平均 $L_1$ 损失。   | $\frac{1}{N}\sum|实际值-预测值|$          |
| $L_2$ 损失          | 预测值与实际值之间的差的平方之和。   | $\sum(实际值-预测值)^2$                   |
| 均方误差（MSE）     | 一组 $N$ 个示例的平均 $L_2$ 损失。   | $\frac{1}{N}\sum(实际值-预测值)^2$        |
| 均方根误差（RMSE）  | 均方根（MSE）的平方根。              | $\sqrt{\frac{1}{N}\sum(实际值-预测值)^2}$ |

在某些情况下，MAE 和 RMSE 等损失指标可能更可取，因为它们往往更易于人工解读，且使用与模型预测值相同的比例来衡量误差。

==MAE 和 RMSE 的差异可能非常大，MAE 表示平均预测误差，而 RMSE 是预测误差的典型数值，并且受较大误差的影响更大。==

==MSE 的数学属性通常会使优化更顺畅，而 RMSE 通常用于将误差恢复为与标签相同的单位。==

在同时处理多个示例时，建议对所有示例的损失求平均值。

## 选择损失

使用 MAE 还是 MSE 取决于数据集以及处理预测的方式。

数据集中的大多数特征值通常处于一个明确的范围内，若超出典型范围，则会被视为离群点。

选择最佳损失函数时，需要考虑如何处理离群值，通常 MSE 会使模型更接近离群点，而 MAE 会更接近大多数数据点。

# 梯度下降

**梯度下降法**是一种数学技巧，可迭代地找到能使模型产生最低损失的权重和偏差。

模型开始训练时，如果需要初始化，会把权重和偏差随机化为接近于零的值，然后重复以下步骤：

1. 使用当前权重和偏差计算损失。
2. 确定可减少损失的权重和偏差的移动方向。
3. 将权重和偏差沿可减少损失的方向移动少量（即**学习速率**）距离。
4. 返回第一步，重复此过程，直到模型无法进一步减少损失为止。

## 模型收敛和损失曲线

通过查看损失曲线，可以确定模型是否收敛。

## 收敛和凸函数

线性模型的损失函数会生成凸面，根据这一属性，当模型收敛时，我们就知道已经找到了最合适的权重和偏差。

==模型几乎找不到可最大限度减少损失的确切权重和偏差，但可以找到非常接近这些值的值。==

# 超参数

**超参数**是控制训练方向的变量，如学习速率、批次大小、周期等。

超参数是受我们控制的量，参数是模型计算出的量。

## 学习速率

学习速率是一个浮点数，用于影响模型收敛的速度。过低，收敛所需时间过长；过高，模型无法收敛，而是在最合适的权重和偏差附近跳动。

我们应当选择一个既不太高也不太低的学习速率，以让模型快速收敛。

学习速率决定了在梯度下降过程中，对权重和偏差所做的更改幅度。

## 批次大小

批次大小是指模型在更新权重和偏差之前处理的示例数量。

有两种常见技术，可以在不查看数据集中每个示例的情况下，获得正确的平均梯度，然后更新权重和偏差。：**随机梯度下降**和**小批量随机梯度下降**。

### 随机梯度下降法（SGD）

在每次迭代中仅使用一个示例。在迭代次数足够多的情况下，SGD 可以正常运行，但**噪声**非常大。

**噪声**是指，训练期间导致损失在迭代过程中增加而非减少的变化。

在整个损失曲线中都可能产生噪声，并不是在接近收敛时才有。

### 小批次随机梯度下降法（小批次SGD）

全批次和 SGD 之间的折中方案。

对于 $N$ 个数据点，批次大小可以是 $1\sim N$ 的任意数字。模型会随机选择每个批次中包含的示例，求梯度的平均值，然后更新权重和偏差。

小批量大小的行为类似于 SGD，大批量大小行为类似于全批量梯度下降。

## 周期数

在训练期间，一个周期是指模型对训练集中的每个示例处理一次。训练通常需要多个周期。

一般来说，训练周期数越多，模型效果越好，但训练时间越长。当训练周期过多时，可能会导致过拟合。
