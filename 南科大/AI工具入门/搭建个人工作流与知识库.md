# 个人工作流

## 添加日程

直接在对话框告诉 Agent 需要干什么即可。

像这种简单的日常小任务（一次性、一步完成、操作固定、无歧义、有现成的App）交给 AI，AI 可能会出错，且会产生花费，所以适合手动完成。

## 每周更新热门电影网站

需要两个部分：AI 生成脚本 + Agent 定时执行任务。

类似工作流（规则明确、流程固定、重复执行），适合 AI 生成固定脚本 + Agent 定时执行并通知。

## 每日自媒体内容生成

- 任务具有创造性，难以用规则描述。
- 术业有专攻，需要分任务，然后使用对应的工具（专业智能体）。

默认 Agent 的文件夹是独立的，而我们要实现这种任务，需要多 Agent 同时作用，所以需要共享文件夹。

而人的作用，就是统筹 Agent 的使用。

## 大型活动规划

Mini Max 有助理，可以进行分工等行为，让统筹更方便。

类似工作流（创造性流程 + 多角色写作），适合使用多个 Agent，让 AI 或人来统筹。

# 个人知识库

## 知识库的文件结构

- 知识库目录

  - 知识库建立的规则

  - 原始资料文件（不可更改）

  - AI 维护的 wiki 文档
    - wiki 总目录
    - 所有操作日志

## 规则

是用来给 AI 看的，让 AI 更好地建立知识库，内容可以包括：

- 文件夹结构
- 添加新资料
- wiki 格式
- 引用来源
- 回答问题
- 定期检查
